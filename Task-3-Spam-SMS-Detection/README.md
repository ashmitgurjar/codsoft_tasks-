# 📱 Spam SMS Detection

## 📌 Overview

This project uses Machine Learning and Natural Language Processing (NLP) techniques to classify SMS messages as **Spam** or **Legitimate (Ham)**.

The model processes the text messages, extracts meaningful features using **TF-IDF Vectorization**, and uses a Machine Learning classifier to predict whether a message is spam or legitimate.

## 🛠️ Technologies Used

* Python
* Pandas
* Scikit-learn
* NLP
* TF-IDF Vectorization
* Machine Learning

## 🎯 Objective

To build an AI-based system capable of automatically identifying spam SMS messages and separating them from legitimate messages.

## ⚙️ Methodology

1. Load the SMS dataset.
2. Clean and preprocess the text.
3. Convert text into numerical features using TF-IDF.
4. Train a Machine Learning classification model.
5. Evaluate the model's performance.
6. Predict whether new SMS messages are Spam or Legitimate.
